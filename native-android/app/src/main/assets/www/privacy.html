Política de Privacidade

Última atualização: 26 de julho de 2026.

Processamento local

O APK processa os links no próprio aparelho. O projeto não exige conta e não envia o histórico, as categorias ou a biblioteca de arquivos para um servidor do aplicativo.

Dados armazenados

O aplicativo mantém localmente o histórico de atividade, categorias personalizadas, favoritos e referências aos arquivos salvos em Downloads/Moura Downloads. Esses dados podem ser apagados pelo usuário.

Permissões

O aplicativo utiliza internet para acessar o endereço informado pelo usuário, notificações para mostrar o progresso e armazenamento para criar e gerenciar os próprios downloads. Não solicita localização, contatos, câmera ou microfone.

Compartilhamento

Ao usar o botão WhatsApp ou o menu de compartilhamento, o arquivo escolhido é entregue ao aplicativo selecionado pelo usuário. A política do aplicativo de destino passa a ser aplicável.

Contato

Antes da publicação pública, substitua esta seção pelo canal oficial do responsável pelo aplicativo.
