# Publicação no Netlify

Este repositório já está configurado para um deploy sem build local.

- Base directory: deixe vazio
- Build command: deixe vazio
- Publish directory: `app`

Depois de publicar, abra o site pelo celular Android e use o botão **Baixar APK agora**. O arquivo é atualizado automaticamente pelo GitHub Actions no mesmo endereço; não copie o APK para a pasta do site.
