# Publicação no Netlify

Este repositório já está configurado para um deploy sem build local.

- Base directory: deixe vazio
- Build command: deixe vazio
- Publish directory: `app`

Depois de publicar, abra o site pelo celular Android e use **Baixar versão rápida**. A versão universal continuará disponível logo abaixo do botão. Os arquivos são atualizados automaticamente pelo GitHub Actions; não copie o APK para a pasta do site.

Quem estiver na antiga versão 3.0 precisa desinstalá-la uma única vez antes de instalar a 4.0 assinada. Depois disso, as próximas versões serão verificadas e baixadas dentro do próprio app em **Ajustes > Atualizações inteligentes**.
